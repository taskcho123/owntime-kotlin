# **OwnTime(온타임)**

## **프로젝트 개요**

사용자의 고정 일정(구글 캘린더)과 자기개발 목표를 기반으로
AI가 하루의 남는 시간을 분석하고 자동으로 자기개발 시간표를 추천해주는 Android 앱.
시간 관리에 어려움을 겪는 현대인에게 도움을 줄 수 있을것이라 예상됨.

### **기술 스택**

* Kotlin
* Android

* Jetpack Compose
* Navigation Compose

* Hilt
* KSP

* Room
* DAO / Entity / TypeConverter
  
* Google Calendar API
* Google Identity / Play Services Auth
* Gemini API
* Firebase Auth
* Firebase Firestore

* Google Calendar 읽기 전용 OAuth 권한(calendar.readonly)
* Firebase 익명 로그인

* SUIT 폰트 사용
* Gradle Kotlin DSL
